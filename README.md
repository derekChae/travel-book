# 나의 여행책

폰으로 찍은 여행 사진을 날짜만 골라 넣으면, 찍은 시각과 장소를 알아서 채워 매거진처럼 엮어주는 개인 여행책.

- 사진과 글은 쓰는 사람의 기기(브라우저) 안에만 저장돼요. 이 저장소에는 앱 코드만 있어요.
- 책으로 뽑기: 인쇄 창에서 PDF로 저장.

## 사용한 자료
- EXIF 읽기: [exifr](https://github.com/MikeKovarik/exifr) (MIT)
- 장소 이름: [GeoNames](https://www.geonames.org/) cities5000 (CC BY 4.0), 이름·나라·좌표만 남겨 줄임
